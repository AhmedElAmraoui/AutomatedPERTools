# SaveFiles Ordner

Hier werden alle Experiment-Ergebnisse automatisch gespeichert:

## Automatisch generierte Dateien:

### Tomografie-Experimente:
- **Standard**: `experiment_results_YYYYMMDD_HHMMSS.json` 
- Beispiel: `experiment_results_20240924_143022.json`

### PER-Experimente:
- **Standard**: `per_results_YYYYMMDD_HHMMSS.json`
- Beispiel: `per_results_20240924_150330.json`

## Dateiformate:
- **JSON (Standard)**: Human-readable, platform-unabhängig, einfach zu inspizieren
- **Pickle**: Kompakter, Python-spezifisch (explizit mit .pkl Endung)
